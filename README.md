# MaaNikki-data

本仓库用于承载 [MaaNikki](https://github.com/architect9331/MaaNikki) 的游戏数据热更新发布包，使客户端无需等待软件发版即可静默同步最新的《无限暖暖》游戏数据。

## 包含范围

- **目录数据包（`catalog`）**：服装评分与焕新数值、奇迹之冠巅峰赛排期与词条、共鸣卡池与深海回响目录、服装获取途径、设计图配方、星海轮换、祝福闪光图鉴及轻量标签元数据。
- **识别资源包（`models`）**：祝福闪光识别模型与背包材料图标特征库（仅在对应模型或图标库发生更新时由客户端按需拉取）。

## 校验与安全

每个发布版本均附带清单与 `SHA-256` 摘要，客户端仅在完整性校验通过后才会将更新原子应用至本地热更覆盖目录，不会修改安装包原始内置资源。
